# Pojang Backend 

A Node.js, Express, and PostgreSQL backend for the Pojangmacha point-of-sale and menu management system.

## Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** PostgreSQL (`pg`)
* **Authentication:** Token-based authentication with crypto hashing
* **Environment Management:** `dotenv`

---

## Getting Started

### 1. Prerequisites
* Node.js installed on your machine.
* PostgreSQL installed and running locally.

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone <your-repo-url>
cd pojang-backend
npm install
